# 测测你最像哪个 AI

一个面向手机和电脑的六题趣味测试，使用 HTML、CSS 和原生 JavaScript。

网站：https://hayasakaaiaiai.github.io/ailike/

包含六种 AI 人设、随机选项、六维度报告、相似度排名、可拖动像素 Logo、深浅色主题和复制分享。支持键盘 1–6 / A–F 答题。

## 本地预览

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173/ 。无需安装依赖或构建。

## 修改内容

- `data.js`：题目、人设文案和分数。
- `app.js`：答题流程、计分、动画和分享。
- `style.css`：响应式布局和深浅色外观。
- `index.html`：页面结构、图标引用和网站信息。
- `logos.js`：内嵌像素 Logo，无需第三方图片服务。

## 部署

GitHub Pages 从 `main` 分支的根目录 `/` 发布。提交并推送修改后，GitHub 会自动更新网站。`.nojekyll` 保持纯静态文件发布。

答案只在当前页面内存中处理；刷新会重新开始。本测试不收集个人资料，不接入真实 AI 模型，也不需要 API 密钥。
